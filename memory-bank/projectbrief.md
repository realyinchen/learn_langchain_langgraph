# Project Brief: AgentLab

## Identity
**AgentLab** is a hands-on learning repository for mastering **LangChain** and **LangGraph**, the leading LLM application frameworks. Authored by realyinchen, it serves as companion code for a WeChat public account series teaching practical LLM application development.

## Core Goals
1. Provide executable, well-documented example code for LangChain and LangGraph concepts
2. Demonstrate real-world LLM application patterns (summarization, agents, routing)
3. Serve as a reproducible learning environment with clear setup instructions
4. Progress from simple to complex implementations to build incremental understanding

## Scope
- **In scope**: Text summarization patterns (MapReduce, Refine, Stuff), LangGraph agent construction, LLM utility abstractions, strategy routing
- **Out of scope** (currently): RAG, chatbots, tool-calling agents, evaluation frameworks, production deployment
